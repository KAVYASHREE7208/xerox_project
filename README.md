# xerox_project
# 🖨️ Xerox Shop Management System

A web-based xerox shop order management system built with PHP and SQLite.

## Features
- 📄 Place orders for Printing, Lamination, Spiral Binding
- 🔐 Admin login to manage all orders
- 📦 Real-time order status tracking
- 💰 Auto price calculation

## Services & Pricing
| Service | Type | Rate |
|---------|------|------|
| Printing | B&W Single side | ₹2/copy |
| Printing | Color Single side | ₹10/copy |
| Lamination | A4 Size | ₹30/page |
| Lamination | ID Card | ₹15/card |
| Spiral Binding | Transparent Cover | ₹25 |
| Spiral Binding | Hard Cover | ₹40 |

## Tech Stack
- PHP
- SQLite Database
- HTML/CSS/JavaScript
- XAMPP (local development)

## How to Run
1. Install XAMPP
2. Clone this repo into `htdocs` folder
3. Start Apache in XAMPP
4. Visit `http://localhost/xerox_shop`
